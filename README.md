# ZED EAST — طريقة شحن كروت عدادات الكهرباء

صفحة اختيار اللغة اللي بيفتحها كود الـ QR، ومعاها الملفات المطبوعة.

**الصفحة:** https://targe2023t-afk.github.io/zed-east-qr/

---

## إيه اللي في المشروع

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية: لوجو ZED EAST + «اختر اللغة لعرض الملف» + زرار English / العربية |
| `english.pdf` | نسخة التعليمات الإنجليزية (صفحة واحدة) |
| `arabic.pdf` | نسخة التعليمات العربية (صفحتان) |
| `QR_Sahl.png` | كود QR بدقة 2048×2048 — للطباعة أو للتصميم |
| `QR_Sahl.svg` | نفس الكود فيكتور — يتكبّر من غير ما تقل جودته |
| `QR_Sahl_Card.png` | كارت مقاس A6 فيه اللوجو والكود والعبارات (عربي/إنجليزي) |
| `QR_Sahl_Card.pdf` | نفس الكارت PDF جاهز للمطبعة |
| `zed.png` | لوجو ZED EAST الأصلي |

## طريقة التجربة
1. افتح كاميرا الموبايل.
2. وجّهها على `QR_Sahl_Card.png` أو `QR_Sahl.png`.
3. دوس على الرابط اللي هيظهر.
4. اختار **English** أو **العربية** — هيفتح ملف الـ PDF على طول.

## ملاحظات
- الصفحة بتشتغل من غير أي مكتبات خارجية: ملف HTML واحد واللوجو مدمج جواه (base64).
- الكارت المطبوع بيستخدم نفس الخط (Segoe UI) للعربي والإنجليزي عشان الشكل يبقى موحّد.
- الكود اتأكد إنه بيتقرأ صح على أكثر من دقة طباعة (لحد 100dpi).
- لو عايز تغيّر الملفات: استبدل `english.pdf` / `arabic.pdf` بنفس الأسماء، وارفع التعديل — الصفحة هتتحدّث لوحدها.
- لو رابط الصفحة نفسه اتغيّر، لازم نولّد QR جديد.

## How to update
Replace `english.pdf` / `arabic.pdf` (keep the same names) and push. GitHub Pages rebuilds automatically.

```bash
git add -A
git commit -m "update PDFs"
git push
```
